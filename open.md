## 📋 Instructions

1. Paste your YAML or text-based spec into `spec.yaml` in this repo and save it. 
2. Click the button below to run Foundry  
3. Your new GitHub repo will be created with the full structure and files  
4. We’ll clean up the project folder once it's built
